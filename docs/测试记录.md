## 测试中发现并修复的问题

| 问题 | 现象 | 原因 | 处理 |
| --- | --- | --- | --- |
| 项目记录丢失 | 重启后项目台账为空 | 写入 7 个字段（`PROJECT|id|name|stack|stage|link|note`），读取却要求 `size() >= 8` | 修正为 `>= 7`，并回归测试 T10 |
| 已完成任务仍显示逾期 | 完成的任务在"剩余"列显示"逾期 3 天" | 剩余天数只按日期计算，未判断完成状态 | 完成的任务固定显示"已完成" |
| 路线重复生成 | 技能分数变化后重新生成会出现重复任务 | 仅按完整标题去重，标题含"当前 N 分"会变化 | 改为"同技能 + 同分类"去重 |
| 表格中文错位 | 岗位/任务列表列宽不齐 | 按字节长度补齐，未考虑 CJK 占 2 格 | 实现 `displayWidth()` 按显示宽度对齐 |
| 空输入误触发操作 | 管道输入结束时可能进入删除分支 | `getline` 失败后返回空串，被当作默认选项 | 增加 `g_inputClosed` 标志，所有菜单循环安全退出 |

网页版测试中发现并修复：

- 已完成任务在列表中仍显示"逾期 N 天"，改为显示"已完成"；
- 头部与内容区容器宽度不一致，统一为 1180px 内容容器；
- **"从零开始"后示例提示条不消失**：提示条用 `hidden` 属性控制显隐，但 `.banner{display:flex}`
  覆盖了浏览器默认的 `[hidden]{display:none}`。已增加全局 `[hidden]{display:none !important}` 修复，
  并回归验证"重置 → 刷新 → 重新载入示例"三种状态。

## 复现方式

```bash
# 编译
g++ -std=c++17 -O2 -static -o zysygh.exe src/zysygh.cpp

# 首次运行（交互）
./zysygh.exe

# 非交互冒烟测试（示例：载入示例数据 → 看板 → 退出）
printf '7\n3\ny\n0\n6\n\n0\n' | ./zysygh.exe
```
