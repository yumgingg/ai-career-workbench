# 使用指南

> 5 分钟上手：填写档案 → 查看匹配 → 生成路线 → 推进任务 → 每周复盘

## 一、第一次打开会看到什么

网页版第一次打开时是**空白档案**：

1. 弹出**欢迎页**，介绍三步用法；
2. 页面里姓名是"同学"、13 项技能都是 0 分、没有任务和项目；
3. 概览顶部有一张"先花 2 分钟，建立你的第一份规划"的提示卡。

进入方式：

| 你的目的 | 操作 |
| --- | --- |
| 填写自己的档案 | 欢迎页「开始填写档案」/ 提示卡「开始填写档案」/ 顶部「我的档案」按钮 / 标签「我的档案」 |
| 先看看完整效果 | 欢迎页「载入示例看看」，或「数据 → 载入示例」 |
| 看详细说明 | 欢迎页「查看操作指南」，或顶部「指南」标签 |

> 示例数据不会占默认：只有点了「载入示例」才会出现示例（林晓，大三）和顶部的提示条；
> 点提示条上的「从零开始」即可恢复空白档案。

> 每个人的数据都只存在自己浏览器的 localStorage 里。老师、同学打开同一个链接时看到的都是空白档案，
> 不会看到你的任务和项目。

## 二、三步开始

### 第 1 步：完善档案与技能自评

- 打开「我的档案」，填写姓名、年级、每周可投入小时数，选择目标岗位；
- 给 13 项技能打 0~5 分，右上角匹配度会实时变化；
- 打分越真实，岗位匹配度和学习路线越准。

### 第 2 步：看岗位匹配，确定方向

- 打开「岗位匹配」，7 类 AI 岗位按匹配度从高到低排列；
- 点「查看详情」看逐项技能差距（你的水平 vs 建议目标）；
- 拿不定主意时可以先都看看，选定后点「设为目标」。

### 第 3 步：生成路线，落到任务

- 打开「学习路线」，看到 26 周的四阶段安排；
- 点「一键生成阶段任务」，路线会变成 12 条带截止日期的任务；
- 之后每天/每周在「任务」页勾选完成即可。

## 三、每个页面做什么

| 页面 | 用途 | 建议频率 |
| --- | --- | --- |
| 概览 | 目标岗位匹配度、完成率、逾期情况、下一步建议 | 每次打开 |
| 我的档案 | 基本信息、技能自评 | 每学期 / 学完一门课 |
| 岗位匹配 | 比较岗位、看差距、切换目标 | 定方向时 |
| 学习路线 | 四阶段安排、生成任务 | 每学期初 |
| 任务 | 新增、完成、筛选、逾期提醒 | 每天或每周 |
| 项目 | 课程项目、竞赛、实习的产出与复盘 | 每个项目结束 |
| 数据 | 导出/导入 JSON、示例数据、清空 | 换设备前 |
| 指南 | 本说明 | 随时 |

## 四、技能评分标准

| 分数 | 含义 |
| --- | --- |
| 0 | 未接触 |
| 1 | 了解概念，没动过手 |
| 2 | 跟着教程做过 |
| 3 | 独立完成课程项目 |
| 4 | 完整项目 / 实习中用过 |
| 5 | 能指导他人、有可展示成果 |

匹配度公式：

```
匹配度 = Σ(技能权重 × 当前等级) ÷ Σ(技能权重 × 5) × 100%
```

技能权重：核心 3 分、重要 2 分、加分 1 分；建议目标等级分别为 4 / 3 / 2 分。

## 五、数据与备份

- 数据保存在**当前浏览器**的 localStorage，不上传服务器，清除浏览器数据会丢失；
- 换电脑、换浏览器前：打开「数据」→「下载 JSON」；
- 到新设备：打开「数据」→「选择文件」导入；
- 想重新开始：「数据」→「清空任务与项目」只清任务和项目；
  「重置全部数据」会连档案、技能一起清空，浏览器里残留的示例数据也用它清除。

## 六、常见问题

**Q：老师打开链接会看到我的数据吗？**
不会。每个人的浏览器各自存储，互不相通。老师第一次打开看到的是空白档案，可以自己填写。

**Q：匹配度为什么是 33%？**
按目标岗位的技能权重和自评等级加权计算。把差距最大的几项技能分数提上去，匹配度会明显变化。

**Q：生成的 12 条任务是什么？**
来自四阶段路线：基础补齐、核心进阶、项目实战、求职冲刺，截止日期分别对应第 6 / 14 / 22 / 26 周。

**Q：任务逾期了怎么办？**
要做就改截止日期，不做就删除；概览页会按截止日期提示最近的三件事。

**Q：能多人协作吗？**
不能。这是个人规划工具，数据在本地；需要共享时导出 JSON 发给对方导入。

**Q：手机上能用吗？**
可以，页面已适配手机宽度，标签栏可左右滑动。
