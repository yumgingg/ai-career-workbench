# 设计说明

## 1. 项目概述

「人工智能专业 · 职业生涯规划学习实践工作台」是一个面向 AI 专业本科生的命令行工具。
它把职业规划从"写一份计划书"变成"每周可执行的任务 + 可量化的进展"，核心闭环为：

```
技能自评 → 岗位匹配 → 差距分析 → 学习路线 → 任务执行 → 项目沉淀 → 数据复盘
   ↑                                                                    │
   └──────────────────────── 数据存档，持续迭代 ──────────────────────────┘
```

选择控制台 + 单文件实现的原因：课程作业需要易编译、易演示、易讲解；无第三方依赖可以保证在
任意装有 g++ 的机器上一次编译通过；纯文本存档便于检查与手工修正。

## 2. 需求分析

### 2.1 用户与场景

| 用户 | 场景 | 诉求 |
| --- | --- | --- |
| 大二/大三 AI 专业学生 | 确定方向、准备实习 | 知道自己离目标岗位差什么，先学什么 |
| 正在做课程项目的学生 | 项目多但零散 | 把项目沉淀成可写进简历的成果 |
| 准备秋招/考研的学生 | 时间紧、任务多 | 按截止日期推进，避免遗漏和拖延 |

### 2.2 功能需求

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| F1 | 记录个人基本信息与目标岗位 | 必须 |
| F2 | 对 13 项 AI 核心技能做 0~5 分自评 | 必须 |
| F3 | 内置多类 AI 岗位的技能要求，计算匹配度并排名 | 必须 |
| F4 | 输出目标岗位的技能差距清单 | 必须 |
| F5 | 按目标岗位生成分阶段学习路线 | 必须 |
| F6 | 学习路线一键转为带截止日期的任务 | 必须 |
| F7 | 任务的增、删、完成、撤回、筛选、逾期提醒 | 必须 |
| F8 | 实践项目台账（技术栈、阶段、链接、复盘） | 必须 |
| F9 | 数据看板（完成率、工时、分类进度、技能画像） | 必须 |
| F10 | 本地存档 / 读档 / 示例数据 / 清空 | 必须 |
| F11 | 非法输入容错、输入结束安全退出 | 必须 |
| F12 | 岗位 JD 关键词匹配、周计划视图 | 可选（未实现） |

### 2.3 非功能需求

- **可移植**：C++17 标准库，Windows / Linux / macOS 均可编译；
- **可读**：单文件约 1350 行，按"工具 → 日期 → 模型 → 知识库 → 业务 → 存档 → 界面"分层排列；
- **健壮**：所有输入有范围校验与默认值，存档损坏时能降级到初始化而非崩溃；
- **中文友好**：UTF-8 输出、按显示宽度对齐、Windows 下自动切换代码页。

### 3.3 主流程

```
启动 → 读取 workbench_data.txt
        ├─ 无存档 → 初始化向导（姓名/年级/时长/岗位，可选技能自评）→ 保存
        └─ 有存档 → 解析；解析失败则回到向导
     → 循环：打印头部状态 → 主菜单 → 分发到功能菜单 → 修改后自动保存
```

## 4. 数据结构设计

### 4.1 核心结构体

| 结构体 | 字段 | 说明 |
| --- | --- | --- |
| `Profile` | name, grade, weeklyHours, targetRole, skills | 个人档案；grade 1~4 本科、5~7 研究生 |
| `Skill` | name, level(0~5) | 单项技能自评 |
| `RoleNeed` | skill, weight(1~3) | 岗位对某技能的要求权重 |
| `Role` | name, summary, needs | 岗位定义 |
| `Task` | id, title, category, due, done, hours | 学习/实践任务 |
| `Project` | id, name, stack, stage(0~3), link, note | 实践项目 |
| `Gap` | skill, cur, need, weight | 差距分析中间结果 |
| `RoadmapStage` | title, startWeek, endWeek, items | 路线阶段 |

### 4.2 存档格式

UTF-8 纯文本，`|` 分隔，首行为版本标记：

```
DSH_WORKBENCH|1
PROFILE|林晓|3|15|NLP / 大模型工程师
SKILL|Python 编程|3
TASK|1|完成《动手学深度学习》第 5-6 章|课程|2026-11-13|0|12
PROJECT|1|中文医疗问答 RAG|Python / LangChain / FAISS|1|github.com/linxiao/rag-medqa|数据清洗完成
```

- 写入前对字段做清洗：`|` 替换为 `/`，换行替换为空格；
- 读取时按字段数量校验，非法行跳过；
- 任务 ID 与项目 ID 由 `nextTaskId` / `nextProjectId` 自增，读取后按最大值恢复。

### 4.3 知识库

- **技能目录**（13 项）：数学与统计基础、Python 编程、数据结构与算法、机器学习、深度学习、
  计算机视觉、自然语言处理、大模型与提示工程、数据工程与 SQL、MLOps 与工程化、
  论文阅读与复现、产品与业务理解、沟通与表达。
- **岗位目录**（7 类）：机器学习算法工程师、计算机视觉工程师、NLP / 大模型工程师、数据科学家、
  MLOps / AI 平台工程师、AI 产品经理、科研 / 读研深造；每类岗位给出 5~8 项技能及权重。

## 5. 关键算法

### 5.1 加权匹配度

```
score(role) = 100 × Σ_i w_i × level_i / (5 × Σ_i w_i)
```

其中 `level_i` 为当前技能等级（封顶 5），`w_i ∈ {1,2,3}`。该公式保证：
技能全满时为 100%，全空时为 0%，核心技能缺失对分数的影响显著大于加分项。

### 5.2 差距计算

建议目标等级：`need = 4 (w=3) / 3 (w=2) / 2 (w=1)`；差距 `gap = max(0, need - level)`。
排序规则：先按 `gap` 降序，再按 `w` 降序，确保"缺口最大且最核心"的技能排在前面。

### 5.3 路线生成

| 阶段 | 周次 | 内容规则 |
| --- | --- | --- |
| 一 · 基础夯实 | 1–6 | 当前 ≤1 分且存在差距的技能，按权重降序最多取 4 项 |
| 二 · 核心进阶 | 7–14 | 其余存在差距的技能（含阶段一顺延项） |
| 三 · 项目实战 | 15–22 | 权重最高的 3 项技能，各配一个"数据→训练→评估→报告/部署"项目 |
| 四 · 求职冲刺 | 23–26 | 简历、面试准备、投递复盘三项固定任务 |

生成任务时：分类按阶段映射（课程/项目/求职），截止日期 = 今天 + 阶段结束周 × 7 天，
工时按阶段给默认值（18h / 18h / 36h / 6h），用户可在任务管理中修改。

### 5.4 任务去重

对路线中的每个条目生成任务前，检查：

1. 是否存在完全同名任务；
2. 若条目关联技能，是否存在"同分类且标题包含「技能名」"的任务。

命中任意一条即跳过，因此反复点击"生成路线任务"不会重复堆积；技能分数变化后重新生成也不会产生
同一技能的副本。

### 5.5 日期序列号

采用 Howard Hinnant 的公历算法，把日期映射为"距 1970-01-01 的天数"：

```
days = era×146097 + doe − 719468
```

优点：纯整数运算，不受时区、夏令时、`mktime` 归一化影响；求天数差、加减天数都是 O(1)。

### 5.6 中文显示对齐

终端中一个 CJK 字符占 2 个字符格，直接按字节或 `std::string::size()` 补齐会导致表格错位。
程序实现 `displayWidth()`：逐 UTF-8 码点解码，CJK/全角区间记 2，其余记 1；配合
`padRight/padLeft/clipTo` 完成定宽输出与超长截断。

### 5.7 输入健壮性

- 所有菜单输入走 `promptInt / promptDouble / promptLine`，带范围校验与默认值；
- 日期支持 `2026-12-31`、`2026/12/31`、`12-31` 三种写法，非法日期提示重试（最多 3 次）；
- 输入流结束（管道/重定向）时设置全局标志 `g_inputClosed`，所有循环安全退出并保存，
  避免读空导致的死循环。

## 6. 界面设计

```
主菜单
├── 1 个人档案与技能自评 ── 修改基本信息 / 逐项自评 / 单项修改
├── 2 岗位图谱与匹配分析 ── 排名表 / 岗位详情 / 设为目标岗位
├── 3 学习路线与阶段任务 ── 四阶段展示 / 一键生成任务
├── 4 任务管理 ─────────── 新增 / 完成 / 撤回 / 删除 / 筛选
├── 5 实践项目台账 ─────── 新增 / 更新阶段 / 编辑链接备注 / 删除
├── 6 数据看板 ─────────── 进度 / 分类 / 技能画像 / 项目分布 / 建议
├── 7 数据管理 ─────────── 保存 / 读取 / 示例数据 / 清空
└── 0 保存并退出
```

头部固定展示：姓名、年级、每周投入、目标岗位与匹配度、任务完成数、逾期数、项目数。

## 8. 不足与改进

| 不足 | 影响 | 改进方向 |
| --- | --- | --- |
| 技能与岗位权重为内置经验值 | 个体差异大时匹配度参考性有限 | 支持自定义岗位、粘贴 JD 自动抽取关键词与权重 |
| 任务只有截止日期，没有周视图 | 难以安排"本周三件事" | 增加按周聚合视图与每日投入建议 |
| 无提醒推送 | 依赖用户主动打开 | 导出 `.ics` 日历或桌面通知 |
| 单机文本存档 | 多设备需手动拷贝 | SQLite + 可选云同步 |
| 控制台界面 | 展示效果一般 | 增加 Web 版或 Qt 图形界面，复用同一数据模型 |
